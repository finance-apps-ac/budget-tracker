# Budget — Annual Tracker

A clean, private annual budget. Track income and expenses month by month, see monthly
net (income − expenses) on a chart, and totals per category. Multi-year — add as many
years as you like. Light & dark theme (follows your system, with a toggle).

**Everything stays on your device.** Data is saved in your browser's local storage and
is never uploaded — there is no account and no server.

## Live demo
Open `demo.html` to see the tracker pre-filled with a full year of example income and
expenses — a quick way to preview how it looks once filled in. The demo uses sample data
held in memory only; it never saves anything and never touches your real budget.

## Run it
Just open `index.html` in any modern browser, or host the folder as a static site
(GitHub Pages, Netlify, etc.). It's a single self-contained HTML file — no build step.

## Install as an app
On iPhone/iPad or Android: open the hosted page, then **Share → Add to Home Screen**.
It launches full-screen with its own icon (PWA).

## Files
- `index.html` — the whole app
- `manifest.webmanifest`, `icon-*.png`, `icon.svg` — installable-app metadata + icons
